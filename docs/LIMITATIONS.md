# Limitations

The database has wide West Bengal evidence coverage but not enough current economic evidence for a
real venture selection. Census counts are 2011 observations, livestock counts are 2019, OSM is
volunteered and incomplete, HCES/ASUSE are sampled and login-gated, and PMMY screening is not lender
approval. Current LGD/PIN reconciliation, prices, incumbent capacity, venture costs, full supply
calibration, MILP MVV, expanded shocks and PostGIS runtime validation remain incomplete.
